## Overview

Karts and tracks are minted as NFTs. Players enter tournaments using crypto; an on-chain payout model distributes rewards to winners and track owners.

The frontend renders a canvas-based race animation and integrates wallet-ready flows for entry and settlement.

## Highlights

- NFT assets for karts and tracks
- Tournament entry in crypto
- Simple, auditable payout mechanics
- Canvas animation front-end

## How It’s Built

- **Solidity** smart contracts mint NFT karts/tracks and handle tournament entries and payouts to winners/track owners.
- Frontend uses **React** + **Vite** with **TypeScript** and a custom **Canvas** race animation.
- Wallet-ready flows via **Ethers.js**; UI integrates entry, race preview, and on-chain payout claim.
- Deterministic race summaries recorded to keep payouts auditable for demos.

## Stack

- Contracts: **Solidity**
- Tooling: **Hardhat**/**Foundry**
- Frontend: **React** + **Vite**, **TypeScript**, **Tailwind CSS**
- Web3: **Ethers.js**
- Deployment: **Vercel**
