## Description

A secure and user-friendly Bitcoin wallet for managing your digital assets.

### Features
- Create new wallets
- Import existing wallets via seed phrase
- Send and receive Bitcoin
- View transaction history
- Real-time price updates

### Security
Your private keys never leave your device. All sensitive data is encrypted locally using industry-standard algorithms.
