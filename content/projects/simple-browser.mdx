## Description

A simple Electron + React browser application built with Vite.

### Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run in development mode:
   ```bash
   npm run dev
   ```

### Build

To build the application:
```bash
npm run build
```

### Start

To start the production build:
```bash
npm start
```
