## Description

A simple browser-based first-person shooter game built with Three.js and Vite.

### Prerequisites
- Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/juliannicb/simple-counterstrike-game.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Game

Start the development server:
```bash
npm run dev
```

Open your browser and navigate to the URL shown in the terminal (usually http://localhost:5173).
