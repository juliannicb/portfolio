## Overview

Demonstrates fractional ownership via an ERC20 share token with simulated oracle updates and a trading UI to buy/sell demo shares.

### Components

- Smart contract: ERC20 share token with configurable oracle price updates (e.g., `contracts/RealWorldAssetToken.sol`).
- Oracle adapter: Minimal, owner‑controlled adapter to push price ticks deterministically for demos (e.g., `contracts/OracleAdapter.sol`).
- Frontend: React + Vite UI to visualise performance, simulate oracle ticks, and buy/sell demo shares.

### Documentation Notes

- Trust boundaries are explicit; updates are auditable.
- Adapter design keeps demos deterministic while illustrating oracle flow.
- Non‑custodial architecture and high‑level regulatory considerations for tokenised fractions.

## How It’s Built

- **Solidity** ERC20 share token contract exposes supply and ownership; an owner‑controlled **Oracle Adapter** pushes deterministic price ticks for demos.
- Frontend built with **React** + **Vite** and **TypeScript** to visualise price performance, simulate oracle ticks, and support demo buy/sell flows.
- Clear trust boundaries and auditable updates are emphasised; adapter is intentionally simple to demonstrate oracle integration.

## Stack

- Contracts: **Solidity** (ERC20), Oracle Adapter
- Tooling: **Hardhat**/**Foundry**
- Frontend: **React** + **Vite**, **TypeScript**, **Tailwind CSS**
- Deployment: **Vercel**
