## Description

This project uses Ethereum to track the supply chain of coffee through various stages: harvested, processed, packaged, shipped, and sold.

### Features
- Track coffee state
- Decentralized data storage

### Usage

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start Ganache:
   ```bash
   ganache-cli
   ```

3. Migrate contracts:
   ```bash
   truffle migrate
   ```

4. Run tests:
   ```bash
   truffle test
   ```

5. Start the app:
   ```bash
   cd client && npm start
   ```
