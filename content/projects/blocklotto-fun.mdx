## Overview

Players choose a number from 0–999 and submit using a commit–reveal scheme to prevent front‑running. Rounds settle against on-chain finality and 70% of deposits pay out to winners.

Entries cost **5 USDC** and multiple entries are supported.

## Design Notes

- Commit–reveal to secure user guesses
- Deterministic payout split and secure claim flow
- Transparent randomness via on-chain finality
- Clear round lifecycle and stakes

## How It’s Built

- Smart contracts in **Solidity** implement commit–reveal: users submit a commitment `hash(pick, nonce)`, then reveal `pick` + `nonce` for verification.
- Settlement references **on-chain finality** to avoid manipulation, with a transparent payout split (70% to winners) and secure claim flow.
- Frontend built with **Next.js** + **TypeScript**, integrating **Ethers.js** for wallet interactions and USDC payments.
- Uses **Base Sepolia** for test rounds and **USDC** as entry token (5 USDC per pick). Multiple entries supported.
- Serverless endpoints provide cached round and entries data for fast UI while reads remain verifiable on-chain.
